## Common Arguments

### -fea
<span style="color:#404040">Argument "\-fea" : Report BIOS supported functionalities\.</span>

Type command "H2OUVE \-fea"

![](img/H2OUVE_User_Guide5.png)

![](img/H2OUVE_User_Guide6.png)

### -r 

<span style="color:#404040">Argument "\-r" : Dump the BIOS ROM regions \(e\.g\. Variables\, Settings\, Strings\, etc\.\) to raw file</span>

Type command "H2OUVE \-r \<file>"

![](img/H2OUVE_User_Guide7.png)

![](img/H2OUVE_User_Guide8.png)

### -a/-l/-c

<span style="color:#404040">Argument "\-a"\, "\-l" and "\-c"</span>

* <span style="color:#262626">Type command "H2OUVE \-a"</span>
  * <span style="color:#262626">System will be Reboot  </span>
* <span style="color:#262626">Type command "H2OUVE \-l"</span>
  * <span style="color:#262626">System will load Optimal default after the next reboot\.</span>
  * <span style="color:#262626">If this command execute without command "\-a"\, then it'd show warning message\.</span>
* <span style="color:#262626">Type command "H2OUVE \-c"</span>
  * <span style="color:#262626">System will load Custom default\.</span>

### -sc

<span style="color:#404040">Argument "\-sc" : Save custom setup default settings\.</span>

* Type command "H2OUVE -sc"
  * Load setting from current value and save to  <span style="color:#0070C0"> __custom default__ </span> \.
* Type command "H2OUVE -sc \<File>" \( <span style="color:#FF0000">\<File> parameter will be __deprecated__ in the future\.</span> \)
  * Load setting from specified file and save to  <span style="color:#0070C0"> __custom default__ </span> \, the file could be generated by "\-gs \-all" or "\-gd \-i"
  * Warning:
    * File dumped from "\-gs \-all" might contain duplicate items\, please remove those before using\.
    * File dumped from "\-gd \-i" might lost some options due to its conditional expression\.
  * Try to execute "\-gs"\, "\-ss"\, "\-sc" in a row instead of input a file to "\-sc"

![](img/H2OUVE_User_Guide9.png)
