## Setup editor

### Modify setup settings

* <span style="color:#262626">Click on "Setup Editor" to switch to Setup editor</span>
* <span style="color:#262626">In different mode\, Setup Editor loads different settings</span>
  * <span style="color:#262626">Runtime mode: Load current settings that system is running</span>
  * <span style="color:#262626">Image mode: Load default settings of BIOS image</span>
* <span style="color:#262626">Different save operation</span>
  * <span style="color:#262626">Runtime mode: Save changes when leaving with "Save and Exit"</span>
  * <span style="color:#262626">Image mode: Save changes when leaving with "Save and Exit" then click "Save button"</span>
