## String editor

An editor used to modify strings show in BIOS

<span style="color:#262626">String Editor supports in </span>  <span style="color:#FF0000">image mode only</span>

<span style="color:#262626">Press "String Editor" to start variable editor</span>

![](img/H2OUVE_User_Guide196.png)

![](img/H2OUVE_User_Guide197.png)

Introduce interface of String Editor

<span style="color:#262626">Please remember that there is no String Editor when it's runtime mode\, it shows when it's image mode\.</span>

Select string packages\, it shows remain chars between \(\)

Tab to switch to string list

![](img/H2OUVE_User_Guide198.png)

Adjust size of column by moving this edge line

Modify strings

<span style="color:#262626">No matter in runtime mode or image mode\, it needs to click "Save button" to save changes</span>

Make sure that remaining space is available if new string needs more spaces

A new Edit menu used to find specific string

![](img/H2OUVE_User_Guide199.png)

Select string package and language you want to modify

Click  __Save button__  to save all changed strings

Double click on selected string to modify it

Find specific string

* <span style="color:#262626">Find string by click funcitons under Edit menu</span>
* <span style="color:#262626">Find string by hotkeys</span>
  * <span style="color:#262626">Find: Ctrl \+ F</span>
  * <span style="color:#262626">Find next: F3</span>
  * <span style="color:#262626">Find previous: Shift\+F3</span>
