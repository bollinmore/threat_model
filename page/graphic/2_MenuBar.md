## Menu Bar

__File menu__

<span style="color:#262626">Functions in file meu enabled by activated editor\.</span>

Switch runtime or load a BIOS image

![](img/H2OUVE_User_Guide173.png)

Save: Save settings to runtime or loaded BIOS image

Save as: It's available when BIOS image loaded

Dump BIOS region data into file

These 2 functions enabled when switch to some editor such like Setup Editor and Variable Editor
