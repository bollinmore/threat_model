## Main Gui

Editors of graphical H2OUVE

* <span style="color:#262626">There are 3 editors in H2OUVE</span>
  * <span style="color:#262626">Setup editor: run setup web page to modify BIOS settings\.</span>
  * <span style="color:#262626">String editor: load setup strings and BIOS browser strings if any\.</span>
  * <span style="color:#262626">Variable editor: load all variables\.</span>
