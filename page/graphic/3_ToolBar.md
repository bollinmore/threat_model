## Tool Bar

__Tool buttons changed by current mode and activated editor\.__

__BIOS image Button__

Same as File>Image to switch to load BIOS image

__Save Button__

Same as File>Save to save current settings

__Display Bit Button__

Display raw data in 8/16/32/64 bits and they are available when switch to Variable editor

![](img/H2OUVE_User_Guide179.png)

__Back to Previous Button__

Used to go back to the up level page

__Runtime Button__

Same as File\->Runtime to switch to runtime mode

__Refresh Button__

Drop all changes and load current settings
