# Graphical Mode

Introduce graphical mode

* <span style="color:#262626">Both Windows and Linux version support graphical mode\.</span>
  * <span style="color:#262626">Linux version  supports Linux kernel 2\.6\.18 and later\.</span>
* <span style="color:#262626">Running H2OUVE and -g argument will open graphical mode\.</span>
* <span style="color:#262626">When graphical mode initialized\, it opens with empty window\.</span>
* <span style="color:#262626">Users can load runtime settings or image settings by clicking runtime & image buttons\.</span>
* <span style="color:#262626">When loading BIOS image\, it loads all settings in that image\.</span>
