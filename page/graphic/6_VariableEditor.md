<span style="color:#262626">Fill Name\, GUID and change data size to add raw data</span>

Modify variable in runtime mode

<span style="color:#262626">Select variable listed in List Panel</span>

<span style="color:#262626">Click mouse right button selected variable to show context menu</span>

<span style="color:#262626">Choose  _Modify _ function to pop\-up a Variable dialog with existing name\, GUID\, data size and raw data</span>

<span style="color:#262626">The Name and GUID fields are read\-only</span>

<span style="color:#262626">Users can only modify the data size and raw data</span>
